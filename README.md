An entry for the [Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4) bounty on make.fun: a single emoji that stands for my AI agent.

> 🧭

A compass. An AI agent finds the way and gets things done on your behalf — it charts the route, not just the map. It reads instantly at small size, and it says something specific about how the agent works: it navigates, orients, and points you where you need to go. No robot, no smiley — the tool that finds the way.

## Run it

```sh
node main.ts
```

This validates the entry (exactly one emoji, 1–16 characters, non-whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
